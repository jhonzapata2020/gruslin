## 📌 Misión y Visión Oficiales

### 🎯 Misión
Promover la capacidad investigativa de los docentes y estudiantes mediante la innovación y la competitividad impulsando, liderando y participando en proyectos novedosos, coherentes y útiles; favoreciendo el progreso y desarrollo mediante la utilización de metodologías de investigación avanzadas enfocadas en el desarrollo social y sostenible.

Proyectarse como un referente en los temas de investigación y desarrollo sostenible a nivel nacional e internacional, que promueve el manejo ambiental, tecnológico, académico y la proyección social mediante el uso de las TIC con apoyo en redes de conocimiento participativo.

## 🛠️ Instalación y Ejecución Local

### 1. Clonar el Repositorio
```bash
git clone https://github.com/semillero-gruslin/landing-page.git
cd landing-page
```

### 2. Instalar Dependencias
```bash
npm install
```

### 3. Ejecutar en Modo Desarrollo (Puerto 3000)
```bash
npm run dev -- --port 3000 --host
```
Navega a [http://localhost:3000](http://localhost:3000) para ver la aplicación en vivo.

### 4. Compilar para Producción
```bash
npm run build
```
